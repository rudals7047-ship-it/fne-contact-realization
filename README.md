## Overview

This repository contains materials associated with the manuscript:

> *Geometry Poorly Predicts Contact Realization in Granular Force-Network Ensembles*

The study investigates the relationship between coordinate geometry, realized contact networks, and force predictability in photoelastic granular force-network ensembles (FNE), using publicly available datasets.

## Repository structure

- `paper/` — manuscript PDF and source files  
- `figures/` — manuscript figures  
- `code/` — analysis scripts  
- `supplementary/` — supplementary materials

## Data sources

This work uses publicly available datasets, including:

- Kollmer & Daniels (2019)  
- Liu et al. (2021)  
- Johns Hopkins Turbulence Database (JHTDB)  
- GlassBench

Please obtain datasets from the original sources.
